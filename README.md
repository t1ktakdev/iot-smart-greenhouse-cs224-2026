# IoT Smart Greenhouse — учебный прототип

## Запуск
Рекомендуется открыть папку в VS Code и запустить Live Server. Альтернатива: `python -m http.server 8080` в папке и перейти на `http://localhost:8080/index.html`. Для Chart.js необходим доступ к CDN. Если CDN недоступна, отображается резервный Canvas-график (не Chart.js). Все IoT-показания виртуальные.

## Как показать
1. Откройте `sensors.html`; выберите ZONE-01 и задайте влажность почвы 20%, воду 75%.
2. Откройте `control.html`, выберите AUTO: насос должен быть ON.
3. Установите уровень воды 10%: насос блокируется, в `alerts.html` появляется Critical.
4. Проверьте температуру 34°C / 16°C и низкую освещённость; покажите переключения вентилятора/нагревателя/света.
5. Переключите MANUAL, измените переключатели, вернитесь в AUTO.
6. Откройте `analytics.html`: четыре графика, Risk Score и рекомендации.
7. Проверьте сохранение после перезагрузки, мобильный вид 390 px, консоль.
